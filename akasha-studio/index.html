        Akasha Language Reference
        
        
      
        
      
        
        
        
          
        KeywordTelugu MeaningDescription / Example
        
          
            
        cheppu(...)చెప్పు (Tell / Print)Outputs values to the console.
        
            
        viluvaవిలువ (Value)Declares a mutable variable: viluva x = 10
        
            
        sthiramస్థిరం (Constant)Declares an immutable constant: sthiram PI = 3.14
        
            
        okavelaఒకవేళ (If)Conditional branch: okavela x > 0 { }
        
            
        mariyuమరియు (And / Else if)Additional branch or logical AND.
        
            
        lekapotheలేకపోతే (Else)Fallback conditional branch.
        
            
        prathi ... loప్రతి ... లో (For-each)Loop iteration: prathi i lo 0..10 { }
        
            
        alaaఅలా (While)While loop: alaa count > 0 { }
        
            
        karyamకార్యం (Function)Function declaration: karyam add(a, b) { }
        
            
        phalithamఫలితం (Result / Return)Returns value from function: phalitham a + b
        
            
        muppuముప్పు (Closure / Lambda)Anonymous lambda: muppu(x) => x * 2
